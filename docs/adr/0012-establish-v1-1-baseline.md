# Establish the v1.1.0 baseline

v1.1.0 uses devicectl as its only production injection path and verifies Apply through current Core Location observations; the earlier GPX observation workflow and its dedicated test gate are retired. To keep one maintained baseline, we remove old LaunchAgent/Guardian cleanup, legacy session conversion, and bookmark coordinate repair; persisted input must already be selection schema 3 or saved-location schema 2 with WGS84 coordinates, and unsupported input is rejected rather than silently reinterpreted or erased. This supersedes the migration requirements in the round-two UI specification and the historical installer retirement step in ADR-0011; current pairing authorization, signed installation, real Clear, renewal recovery, and production-path smoke coverage remain required.
