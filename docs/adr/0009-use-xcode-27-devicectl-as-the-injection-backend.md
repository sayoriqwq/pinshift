# Use Xcode 27 devicectl as the injection backend

Xcode 27's public `devicectl device simulate location` commands are the sole production Injection Backend for the current personal environment. The controller invokes `/usr/bin/xcrun` with argument boundaries, a fixed `DEVELOPER_DIR`, a sanitized environment, and one configured Active Test Device selector; successful `coordinate` and `clear` exits acknowledge Apply and Clear while Pinshift app observation remains separate verification.

The earlier XCUITest candidate passed its bounded Stage A probe, but the long-running controller runner later failed repeatedly in Xcode's DTX handshake before its test method began. On the same physical device, public `devicectl` successfully applied A, replaced it with B, produced fresh matching observations in the Pinshift app, and cleared the simulation. Replacing the backend preserves the backend-neutral Simulation Controller and Controller Link while removing the runner, per-session credential, and second production path.
