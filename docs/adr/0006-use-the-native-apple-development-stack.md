# Use the native Apple development stack

The project uses Swift 6 and Apple-platform technologies directly: SwiftUI, MapKit, Core Location, Network, Security and Keychain, CryptoKit where applicable, OSLog, XCUITest, Swift Testing, and Swift Package Manager. It deliberately avoids cross-platform abstractions so the implementation exposes and teaches the surrounding Apple development ecosystem. Dependencies follow a deliberate order: use system frameworks first, Apple- or Swift-maintained packages such as Swift Argument Parser or Swift Certificates where the platform lacks a suitable higher-level component, and community packages only after their necessity and maintenance quality are reviewed; the project does not rewrite mature ecosystem components merely to claim zero dependencies.
