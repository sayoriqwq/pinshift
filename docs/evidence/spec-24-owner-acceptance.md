Bonjour/TLS 连接、Xcode 注入、睡眠/锁屏恢复、定位精度或其他 App 的传播已经通过。
[#21](https://github.com/sayoriqwq/pinshift/issues/21) 的取证与

## 准备本次版本

在本次 PR 的检出目录中连接并解锁自己的 iPhone。保持既有 App 和配对数据，不卸载 App。
首次系统信任、开发者模式或 Xcode Apple 账号登录需要本人处理；已经完成的设置不必重置。

```fish
direnv allow
./bin/pinshift setup
./bin/pinshift app --force
./bin/pinshift doctor
./bin/pinshift
```

🛠️ 加载项目环境，更新控制器并原位安装本次 App 代码，检查设备后进入前台会话。

`setup` 和本次 `app --force` 是版本更新步骤；前者会真实解除遗留模拟，后者确保手机安装的是
本次新界面，避免已有签名尚有效时跳过代码更新。如果从未签过该 App，按提示先在 Xcode
完成一次本项目的签名运行；若 Apple 未返回有效的新 profile，不把续签失败当成安装成功。
进入日常使用后只需运行
`pinshift`。若看到源码变化提示，先更新控制器；不要改用未稳定签名的临时 CLI 绕过信任。
签名维护失败时按终端的登录或解锁提示恢复；仍可用的既有 App/控制器能力不因维护失败被隐瞒。

在 App 的“更多”检查 Mac 连接；既有信任应自动复用，仅未配对时输入终端六位码。确认主页中
没有伪造的默认可应用位置。检查此前收藏、中文/英文偏好与诊断记录仍在。

## 选点与发送一致性

以下坐标与原始日志仅在本机记录。每项都记录 Selected Location 的完整坐标、诊断中的请求坐标、
Mac 后端回执时间、Pinshift 新鲜观测时间及水平精度。显示舍入值不能代替完整发送坐标。

| 操作 | 应看到的结果 |
| --- | --- |
| 搜索并选择 A | 地图与待应用 A 同步；没有 Apply 请求 |
| 搜索无结果、失败或取消 | 已有选择保留 |
| 拖动主地图到 B | 拖动结束更新待应用 B；没有独立“提交中心”或 Done；没有 Apply |
| 点击收藏 C | 只更新待应用 C，地图同步；保存、重命名、删除后重开验证数据 |
| 手动输入高精度坐标 | 待应用与实际发送完整坐标一致，不从显示舍入值恢复 |
| 应用 A | 回执前显示请求进行中；回执后才显示当前 A、三分钟期限 |
| 模拟 A 时搜索/拖动到 B | 同屏显示当前 A 和待应用 B，A 不提前改变 |
| 回到当前地点 | B 恢复为 A，地图回到 A；无 Apply、期限不变 |
| 换个地点… | 聚焦顶部同一个搜索框 |
| 改到这里 · 3 分钟 | 一次点击替换，成功后当前为 B，获得新期限 |
| 快速连续换点或重试 | 后接受的操作不被旧响应覆盖；相同请求 ID 重试不延时 |

## 三分钟与解除恢复

每个到期场景都开始一轮新的 Apply。按 Mac 接受时间记录固定 180 秒期限；不要从手机动画估算。
到期后先看到正在解除/未确认，只有真实后端成功回执才可记为“解除已确认”。

| 场景 | 动作与通过信号 |
| --- | --- |
| Pinshift 前台 | 保持 Mac 会话运行，等待原期限，记录真实 clear 回执及后续新观测 |
| 切到其他 App | 原期限不变，Mac 仍解除；逐 App 单独记录传播结果 |
| 划掉 Pinshift | Mac 仍按原期限解除；重开 App 读取当前状态，不重放旧 Apply |
| 立即解除 | 活动中与没有活动记录时各测一次，均有真实后端 clear |
| 到期设备失联 | 保持 Mac 会话运行，看到解除未确认；恢复数据线/信任/解锁后自动补清理 |
| 解除失败后新 Apply | 仍可选点与提交；新 Apply 成功后，旧重试不得清掉新位置 |
| 正常退出 | 活动中按一次 Ctrl-C，确认真实解除成功后终端才结束 |
| 正常退出时失联 | 按一次 Ctrl-C 后进程继续等待；恢复设备后成功解除并退出 |
| 显式强制退出 | 在清理未确认时按终端提示再次中断，看到未解除警告；下次启动尝试真实遗留清理 |
| Mac 睡眠后恢复 | 睡眠跨过期限，恢复存活前台会话，处理已到期责任；不承诺睡眠期间执行 |
| 进程意外消失后重开 | 下次显式启动即使无活动记录也真实清理；失败不永久阻止新 Apply |
| App 与 Mac 断连重连 | 断连标明状态未确认；恢复后读取 Mac 快照，不重置倒计时 |

断电、进程消失或强制退出期间没有常驻守护清理。强制退出试验结束后务必恢复设备并显式启动或
运行一次 `pinshift clear`，确认真实后端解除结果。

## 精度、残留与辅助功能

对同一个测试点分别核对：选中坐标、发送坐标、后端回执、Pinshift 符合新鲜度条件的 Core Location
样本，以及本人常用 App 的实际显示。按每个 App 记录误差、刷新时间与条件。Clear 回执只能证明
开发者模拟解除，不能证明所有 App 已收到物理位置。旧观测保留为历史证据。

不预设“5 米”“5 秒”或所有 App 同步恢复门槛；按 #21 的事实在 #23 确定。若出现 500 米至 1 公里
偏移，保留坐标链与时序，不添加未经取证的全局补偿或坐标转换。

检查中文/英文、最大辅助字号、VoiceOver、系统深浅色与减少动态效果。搜索、应用、立即解除、
收藏和更多必须可达；按钮触摸范围不小于 44pt。关闭面板恢复焦点，模态期间不能误触主地图；
键盘操作不等待装饰性动画，减少动态效果时没有位移/缩放，倒计时不逐秒布局动画。
